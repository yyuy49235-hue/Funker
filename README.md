Android app (Kotlin + Chaquopy/Python 3.11) that makes FNF / Psych Engine mods lighter.

- Build: GitHub Actions `Build APK` -> artifact `FunkerLiteLab-debug-apk` (APK + BUILT_FROM_COMMIT.txt)
